# 浮动 Widget 布局修复计划

## 问题描述

当前 FloatingWidget.cs 存在以下布局问题：

### 问题 1：标签和百分比重叠
- 标签（9pt）画在 y 位置，底部约 y+13
- 百分比（11pt bold）画在 y+16-5 = y+11，顶部约 y+11
- 重叠区域：y+11 到 y+13（2px）
- 原因：标签到进度条的间距 `y += 16` 不够

### 问题 2：进度条太短，右侧空白
- 进度条宽度 80px，内容区 200px
- 进度条 + 百分比只占约 128px
- 右侧 72px 空白，所有内容挤在左边

### 问题 3：进度条太细
- 进度条高度 4px，在 240px 宽的控件上几乎看不到

### 问题 4：整体间距太紧
- 标签到进度条 16px，进度条到详情 14px，视觉上粘连

## 当前代码实际状态

由于之前部分修改已应用，当前代码中：
- `BarWidth` = 120（已改）
- `BarHeight` = 6（已改）
- `BarPctGap` = 10（已改）
- `CardHeight` = 190（已改）
- DrawQuotaSection 中 `y += 16`（未改，需要改为 22）
- DrawQuotaSection 中 `y += 14`（未改，需要改为 18）

## 修复方案

仅修改 DrawQuotaSection 中的两个 y 增量：

| 项目 | 当前值 | 改为 | 原因 |
|------|--------|------|------|
| 标签→进度条 `y +=` | 16 | 22 | 消除标签和百分比重叠（需 13+4=17px 最小间距） |
| 进度条→详情 `y +=` | 14 | 18 | 增加呼吸空间 |

## 修改后空间验证

DrawQuotaSection 内部逻辑：
```
y = 入口 y 值
标签画在 y，y += 22 → y = 入口+22
进度条+百分比画在 y，y += 18 → y = 入口+40
详情画在 y
return y + 14 → 返回 入口+54
```

每个配额区总高度：54px（标签22 + bar+pct 18 + return 14）

OnPaint 调用流程：
```
y = 14（CardVPadding）

MCP 区：DrawQuotaSection 返回 14+54 = 68
y += 10 → y = 78
分隔线画在 y=78
y += 10 → y = 88

5h 区：DrawQuotaSection 返回 88+54 = 142
y += 10 → y = 152
分隔线画在 y=152
y += 10 → y = 162

统计行画在 y=162
```

逐元素 Y 位置：
```
y=14   MCP 配额（标签 9pt，底部约 y=27）
y=36   [████████████████░░░░] 13%（进度条+百分比）
       进度条 y=36, 高6px → y=42
       百分比画在 y=36-5=31, 11pt约16px高 → y=31..47
y=54   133 / 1.0K（详情 8pt，底部约 y=65）
y=68   返回值
y=78   ──────────────
y=88   5h Token（标签 9pt，底部约 y=101）
y=110  [████████████████████] 94%
y=128  下次重置: 13:29
y=142  返回值
y=152  ──────────────
y=162  1.2K 次调用 | 164M Token（底部约 y=173）
y=190  窗口底部
```

验证：
- 标签和百分比最小间距：31 - 27 = 4px（无重叠）✅
- 进度条+百分比右边界：20+120+10+32 = 182px（内容区 220px）✅
- 最底部元素 y=173，窗口 y=190，余量 17px ✅
- 所有元素在 240x190 范围内 ✅
